# GitHub Repo Explorer 🚀

A web app built with React, TypeScript, and Vite to search and explore GitHub repositories.

## 🛠️ Tech Stack
* React + TypeScript
* Tailwind CSS
* Vite

## 🚀 How to Run Locally

1. Clone the repo:
   git clone https://github.com/Satyam-coder18/github-repo-explorer.git

2. Install dependencies:
   npm install

3. Run the development server:
   npm run dev
